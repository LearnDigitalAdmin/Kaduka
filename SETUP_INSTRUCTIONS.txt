THREE STEPS TO DEPLOYMENT:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Deploy Webhook Handler (5 minutes)
────────────────────────────────────────────

The webhook already exists in @functions/ (Cyber project).
Just deploy it:

  $ cd ~/Desktop/Cyber/functions
  $ firebase deploy --only functions

Then set your Paystack SECRET key:

  $ firebase functions:config:set paystack.secret_key="sk_live_xxxxx..."
  $ firebase deploy --only functions


STEP 2: Configure Paystack Webhook (2 minutes)
──────────────────────────────────────────────

1. Go to: https://dashboard.paystack.com/settings/webhooks
2. Add webhook URL:
   https://YOUR_REGION-YOUR_PROJECT_ID.cloudfunctions.net/paystackWebhook

3. Select these events:
   ✓ charge.success
   ✓ charge.failed

4. Save


STEP 3: Set Firebase RemoteConfig (2 minutes)
──────────────────────────────────────────────

1. Go to: Firebase Console → Your Project → Remote Config
2. Add new parameter:
   Parameter name: paystack_public_key
   Default value: pk_live_xxxxx...

3. Click "Publish changes"

HOW IT WORKS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. User clicks "Upgrade to Premium"

2. App creates: report_charges/{REPORT_shop123_1703001234}
   Status: pending

3. App opens Paystack modal
   Gets public key from Firebase RemoteConfig
   Reference: REPORT_shop123_1703001234

4. User enters M-Pesa PIN

5. Paystack processes payment

6. Paystack sends webhook:
   event: charge.success
   reference: REPORT_shop123_1703001234
   status: success

7. Webhook handler (from @functions/):
   Updates: report_charges/{reference}
   Sets status: success

8. Client listener detects change:
   Fires onSuccess callback

9. App activates subscription:
   Creates: shops/{shopId}/subscriptions/{reference}
   Expiry: now + 7 days (weekly) or 30 days (monthly)

10. User can now generate premium reports! ✅
